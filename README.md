# Surge Engine
### Sonic Framework

Scaleable, Easy and Fast - Boost framework created with Unity 6. Working on High Definition Render Pipeline (HDRP) for an amazing graphics quality.

## Features
- Optimized code (sorta)
- Custom shaders with HE1 graphics technologies
- Easy to add new functionality
- Ported particles from SU and Gens

## Content
- Smooth and flexible physics
- State Machine that controls the character and enemies state
- Mobility gameplay objects like Springs, Dash Panels, Upreels, Jump Panels, Trick Panels and etc
- Enemies Egg Fighters, Aero Cannon, Spinner
- Different damage objects (gimmicks) from Unleashed
- HE1 SetData importer that allows you to easily import framework objects with their parameters from SU (and possibly SG) to your gameplay scene
- Clean and readable code with a single code style
- Recreated VFX from Unleashed/Gens
- Asset Manager window with categories and all framework objects that can be easily added to your custom stage
- Recreated cameras, volumes priority and blending between them
- Inverse Kinematics (IK Foot)
- Dependency Injection for more cleaner code

## Repository Support
You can help this project by fixing bugs or adding new features and adding these changes to the Pull Request

## Installation Guide
1. Clone/Download the repository
2. Add the project to the Unity Hub
3. Download required Unity version and open the project

> [!NOTE]
> You probably want to have the latest updates of the framework.  
> To update, you must have a fork of the repository.  
> Then you need to merge your changes with the main repository and resolve any conflicts, if there are any.
> 
> In general, learn how to use git.

## Knows issues
- Transparent particles don't render underwater if "Use Scene Color" is enabled in water material
